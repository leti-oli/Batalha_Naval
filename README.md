<h2>🚀 Funcionalidades</h2>

<ul>
    <li>⛵ Posicionamento manual das embarcações do jogador;</li>
    <li>⚓ Posicionamento aleatório das embarcações do computador;</li>
    <li>⛵ Validação das coordenadas informadas pelo usuário;</li>
    <li>⚓ Ataques alternados entre jogador e computador;</li>
    <li>⛵ Exibição visual de acertos (💥) e erros (🌊);</li>
    <li>⚓ Contagem de embarcações restantes;</li>
    <li>⛵ Verificação automática de vitória;</li>
    <li>⚓ Interface executada diretamente pelo terminal.</li>
</ul>

<h2>🎮 Regras do Jogo</h2>

<ul>
    <li>Cada jogador possui 5 embarcações.</li>
    <li>As embarcações ocupam apenas uma posição do tabuleiro.</li>
    <li>O jogador posiciona suas embarcações manualmente.</li>
    <li>O computador posiciona suas embarcações aleatoriamente.</li>
    <li>Os ataques acontecem de forma alternada.</li>
    <li>Vence quem afundar todas as embarcações adversárias primeiro.</li>
</ul>
